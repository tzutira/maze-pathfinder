# Генератор лабиринтов и поиск пути

Учебный командный проект №20 по дисциплине «Технологии индустриального программирования». Программа на C++ будет создавать случайный лабиринт и показывать кратчайший путь между двумя выбранными клетками.

## Текущий этап

Выполнен пункт 1 плана: подготовлены границы первой версии, выбор алгоритмов и предложение по распределению работы между тремя участниками. Достаточность выбранного объёма ещё нужно согласовать с преподавателем. Программный код, сбор требований, SRS и UML пока не подготовлены. Публичный репозиторий команда создаёт самостоятельно.

## Первая версия

- Консольный интерфейс.
- Размер лабиринта от 2 до 50 строк и от 2 до 50 столбцов логических клеток.
- Генерация лабиринта алгоритмом поиска в глубину (DFS).
- Выбор начальной и конечной клетки по координатам.
- Поиск кратчайшего пути алгоритмом поиска в ширину (BFS).
- Вывод стен, проходов, выбранных точек и найденного маршрута.
- Проверка ввода и возможность повторить поиск или создать новый лабиринт.
